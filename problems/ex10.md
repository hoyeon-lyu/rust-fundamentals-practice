# 예제 10. 알파벳 빈도
관련 레슨: 11 HashMap

한 줄을 받아 **영문자만** 세고(대소문자 구분 없이, 소문자로 합쳐서), 등장한 글자를 **알파벳 순서대로** `글자: 횟수` 형식으로 출력한다. 공백·숫자·기호는 세지 않는다.

| 입력 | 출력 |
|---|---|
| `Hello World` | `d: 1` / `e: 1` / `h: 1` / `l: 3` / `o: 2` / `r: 1` / `w: 1` |
| `Rust rust!` | `r: 2` / `s: 2` / `t: 2` / `u: 2` |

💡 `HashMap`은 순서가 없다. 키를 `Vec`으로 모아서 정렬한 뒤 출력해 보자. `c.is_ascii_alphabetic()`, `c.to_ascii_lowercase()`가 쓸모 있다.
