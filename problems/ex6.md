# 예제 6. 학점 계산기
관련 레슨: 06 if와 match

점수(정수) 하나를 입력받아 학점을 출력한다. **`match`와 범위 패턴**(`90..=100` 같은)으로 풀어 본다.

| 점수 | 출력 |
|---|---|
| 90 ~ 100 | `A` |
| 80 ~ 89 | `B` |
| 70 ~ 79 | `C` |
| 60 ~ 69 | `D` |
| 0 ~ 59 | `F` |
| 그 밖의 값 | `Invalid` |

| 입력 | 출력 |
|---|---|
| `85` | `B` |
| `100` | `A` |
| `105` | `Invalid` |
