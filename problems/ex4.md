# 예제 4. 글자 수 vs 바이트 수
관련 레슨: 04 String과 &str

한 줄을 입력받아 `trim()`한 `&str`로 네 줄을 출력한다.
1. 소문자로 바꾼 문장
2. 글자 수 (`.chars().count()`)
3. 바이트 수 (`.len()`)
4. 글자 수와 바이트 수가 같은지 (`true` / `false`)

| 입력 | 출력 |
|---|---|
| `  Hello Rust  ` | `hello rust` / `10` / `10` / `true` |
| `  안녕 Rust ` | `안녕 rust` / `7` / `11` / `false` |

한글은 UTF-8에서 한 글자가 3바이트라서 두 값이 달라진다.
